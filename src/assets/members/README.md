# 연구원 사진 폴더

연구실 구성원 프로필 사진을 이 폴더에 올립니다.

## 올리는 방법
1. 사진 파일 이름을 **연구원 마크다운 파일 이름과 똑같이** 지어서 이 폴더에 넣습니다.
   - `src/content/team/hong-gildong.md` → `src/assets/members/hong-gildong.jpg`
   - 확장자는 `jpg`, `jpeg`, `png`, `webp`, `avif` 모두 가능합니다.
2. 마크다운에 따로 적을 것은 없습니다. 파일 이름만 맞으면 팀 페이지와 상세 페이지에 자동으로 나옵니다.
3. 커밋 → 푸시 → PR 머지하면 사이트에 반영됩니다.

사진이 없으면 기본 실루엣이 표시됩니다.

## 사진 규격 (권장)
- 가로 세로 **1:1 정사각형**, 한 변 **600px 이상** (얼굴이 가운데에 오게)
- 용량 **500KB 이하** (너무 크면 페이지가 느려집니다. 큰 사진은 줄여서 올려주세요)
- 배경은 단색이면 카드에서 가장 깔끔합니다.

## 예외
- 이름을 다르게 쓰고 싶으면 마크다운에 `avatar: "../../assets/members/다른이름.jpg"` 로 직접 지정합니다.
- 외부 주소의 사진을 쓰려면 `avatarUrl: "https://..."` 를 적습니다.
